# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/liquidlm/python-sdk/security/advisories/new).
Do not open public issues for security reports. If the advisory channel is
unavailable, use `support@liquidlm.com` with "Security" in the subject.

Never attach tokens, signed URLs or customer content to issues, fixtures or
logs. SDK exceptions carry status and request IDs only; do not log request or
response bodies when reporting failures.

Supported versions: fixes land on the latest alpha prerelease.
