# Changelog

## 0.1.0a0 — source candidate

- Sync and async clients over one httpx transport with bearer/session auth,
  active-org forwarding, safe error classes and bounded read retries.
- Native QUERY method support, offset and cursor pagination, SSE streaming
  and attempt-protocol uploads without credential leakage to storage URLs.
- Typed models generated from the pinned public OpenAPI contract.
